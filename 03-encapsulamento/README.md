# Encapsulation

This module explores encapsulation in C# through a practical bank account example.

The goal is to understand how a class can protect its internal state and control how that state is accessed and modified.

## Concepts

- Encapsulation
- Private fields
- Public methods
- Constructors
- Controlled access
- Validation rules
- Return values
- Object state
