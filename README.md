# C# Modular Programming

A hands-on study repository focused on programming fundamentals, object-oriented programming, modular design, and software quality using C#.

The goal of this repository is not only to implement examples, but to understand the concepts by writing, running, testing, and refactoring the code.

## Topics

- Software Quality Factors
- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- Generics
- SOLID Principles
- Design Patterns

## Repository Structure

```text
01-fatores-qualidade/
02-classes-e-objetos/
03-encapsulamento/
04-heranca/
05-polimorfismo/
06-generics/
07-solid-e-padroes/
```

Each topic contains practical C# examples developed while studying the concepts.

## Approach

The examples are intentionally developed step by step.
For some concepts, the repository contains different versions of the same problem to demonstrate the evolution from less maintainable code to clearer, more modular, and more maintainable solutions.
